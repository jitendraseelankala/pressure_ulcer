# Pressure Ulcer Detection Project

This project is used for pressure ulcer detection/classification using machine learning.

## Project Files

- `pressure_ulcer.ipynb` - Main Colab notebook
- `requirements.txt` - Required Python libraries
- `README.md` - Project documentation

## How to Run

Open the notebook in Google Colab and run all cells.

## Note

Do not upload private patient data, medical images, API keys, or confidential files.
